# Formula 8

A racing auto battler: build the inside of a race car out of modules, then watch it race 3 laps against 7 rivals on a freshly generated circuit. Made for the Bezi Mega Jam 2026.

## Download

**macOS** (Intel + Apple Silicon, macOS 11+): [Formula8-macos.zip](https://github.com/sergiolinarescodes/formula8/releases/latest). The app is not notarized, so the first launch needs one extra click. The steps are in the release notes.

All builds: [Releases](https://github.com/sergiolinarescodes/formula8/releases)
